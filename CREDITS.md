# Credits

## Test Environment
- **Hardware:** Lenovo ThinkPad X13s Gen 1
- **Platform:** Qualcomm Snapdragon / ARM64
- **Operating System:** Ubuntu Linux

All logs, fixes, and documented workarounds were compiled during active local troubleshooting and system auditing.

## Upstream Projects & Communities
This field log is only possible because of the relentless engineering work done by the upstream open-source community to make mainline Linux viable on Snapdragon hardware. Credit is due to:

- **The `aarch64-laptops` Community:** For pioneering the reverse-engineering and documentation required to boot alternative OSes on ARM64 laptops.
- **Linaro & The Linux MSM Team:** For their massive ongoing effort to upstream Qualcomm (MSM) device trees, power management, and drivers directly into the Linux kernel.
- **The Ubuntu / Debian ARM Porters:** For maintaining the `arm64` (`aarch64`) package repositories and userland architecture relied upon in this environment.
